# ClipCut promo (Remotion)

An independently rendered motion-design project for the ClipCut launch video. The application is authored in QML; this project recreates selected UI components in React/CSS/SVG so each property can be animated deterministically by Remotion.

The video is a personal project: a small, local editor made to cut video clips easily and practically, without turning the workflow into a heavyweight editing suite.

## Requirements

- Node.js 20.19+ or Bun 1.2+.
- npm (lockfile is `package-lock.json`).
- Remotion's supported Headless Chromium. No system Chrome installation is needed; set it up with `npx remotion browser ensure`.
- FFmpeg available for MP4/GIF encoding.
- Python 3 with NumPy (`python3 -c 'import numpy'`) for the original synthesized score.

## Setup and preview

```sh
cd promo
npm ci
npm run prepare:assets
npx remotion browser ensure
npm run studio
```

In the Studio, inspect `ClipCutPromo` (1920×1080, 60 fps, 32 s) and `ClipCutPreview` (1280×720, 30 fps, 8 s loop).

## Render

```sh
npm run render          # output/clipcut-promo-1080p.mp4
npm run render:preview  # output/clipcut-preview.gif
```

Output files are ignored by Git. The MP4 render requires NVIDIA NVENC (`--hardware-acceleration required`, H.264 targeting 12 Mbps with AAC audio at 320 kbps); if NVENC is unavailable, it fails instead of silently falling back to CPU encoding. Remotion's browser still renders the composition frames separately, so this uses the GPU for video encoding, not necessarily every drawing/compositing operation. GIF encoding has no NVENC path; the GIF exports 15 fps from the 30 fps composition.

## Sound and editorial direction (v2)

The 32-second teaser includes an original 120 BPM electronic instrumental, synthesized percussion, click accents and noise sweeps generated by `scripts/create-soundtrack.py`. It uses no samples, recordings, external music or voiceover. NumPy synthesizes the stereo WAV; FFmpeg normalizes it toward -16 LUFS / -1.5 dBTP. `prepare:assets` regenerates it in the ignored `public/audio/` directory.

Six scenes start at 0, 4, 9, 17, 23 and 28 seconds. Eighteen-frame directional wipes (and a final crossfade) connect kinetic typography, a perspective product shot, timeline close-ups with simulated cursor drags, animated crop ratios, an export-panel close-up, and the final project signature. Editorial headings, badges, grid and cursor are presentation graphics, not added app features. The first approved base is preserved locally in `output/v1/`.

## Source of truth

Run `npm run prepare:assets` after editing the source design tokens or brand SVG. The token extractor reads the static ClipCut palette, radii, spacing, typography and layout values from `../DesignTokens.qml`. The brand copier takes the SVG directly from `../assets/branding/`.

See [`docs/interface-mapping.md`](docs/interface-mapping.md) for the QML-to-Remotion mapping and explicit simulation notes. This composition does not execute the ClipCut app/backend and does not claim that its simulated playback or export is real.
